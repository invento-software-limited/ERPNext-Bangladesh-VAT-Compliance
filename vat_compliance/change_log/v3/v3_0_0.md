## [3.0.0] - 2026-11-10

### 💥 Breaking Changes
- **Vat Challan Module Removed**: completely removed the legacy `Vat Challan` module and its 10 doctypes: `POS Vendor Configuration`, `Retailer Registration`, `Retailer Branch Registration`, `Retailer Service Type`, `VAT Invoice`, `VC Circle`, `VC Division`, `VC Service Type`, `VC VAT Commission Rate`, and `VC Zone`.
- **Integration Hooks & Schedulers Removed**: removed `POS Invoice` and `Sales Invoice` submit hooks (`create_vat_invoice`) and daily scheduler job (`auto_sync_vat_invoices`).
- **POS & Item Custom Fields Cleaned**: removed integration custom fields and columns from `POS Profile`, `Item`, `Item Group`, and `POS Invoice Item`.

### 🔧 Changed
- **Compliance Settings**: removed the `API Configuration` tab and vendor proxy/timeout settings (`upstream_proxy`, `enable_proxy`, `request_timeout`). Added comprehensive guidelines for statutory Item Tax Template configuration.
- **Navigation & Workspaces**: removed `Smart Vat Challan (Beta)` desktop icon, workspace, sidebars, dashboard charts, number cards, and reports.
