## [2.3.1] - 2026-11-05

### 🛡 Security
- VAT Deduction Certificate: `certificate_html` and `context` can now only be written by Mushak 6.6 generation, and values sent by a client are discarded. Previously anyone with write access could store script that ran when another user opened the form. The form now shows the certificate in a sandboxed frame that cannot run code.
- Supplier Mushak 6.3: `custom_mushak_63` must be a file the user can read, including on submitted invoices, and the report escapes the value. Previously it could store script that ran for anyone opening the report.
- Mushak 6.1, Mushak 6.2, Trader Ledger, Sales VAT Management, Supplier Mushak 6.3 and VDS Management now enforce company User Permissions. Previously a user restricted to one company could read another company's figures. A restricted user must now choose a company.
- Upload Challan and Mushak 6.3 upload only accept files the user can read.
- Mushak 6.3 **Download All** now needs report access and Sales Invoice print permission, and is limited to 500 invoices.
- Compliance Settings: creating tax templates is POST-only.

### 🐞 Fixed
- Mushak 6.3: choosing a status could include draft and cancelled invoices. The report now always uses submitted invoices, and the Draft and Cancelled options are removed.
